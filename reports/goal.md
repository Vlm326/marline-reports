# Цель работы
Цель работы — разработать и исследовать эффективный обратный индекс для поиска базовых чанков, используемых в алгоритмах similarity-based chunking, обеспечивающий сокращение числа сравнений при поиске похожих объектов и пригодный для интеграции в систему дедупликации.

## Задачи

1. **Спроектировать архитектуру обратного индекса для similarity-based chunking**
   
   Разработать программный интерфейс обратного индекса для хранения связей между идентификаторами чанков, их sketch-представлениями и признаками, используемыми при поиске похожих объектов.

2. **Разработать структуру хранения sketch и posting lists**
   
   Реализовать структуру хранения sketch и обратных списков (`posting lists`), сопоставляющих каждому признаку множество идентификаторов содержащих его чанков. Реализовать операции чтения, добавления, удаления и очистки записей.

3. **Реализовать операции управления записями индекса**
   
   Реализовать добавление, удаление и обновление записей обратного индекса, обеспечив согласованность хранимых sketch и posting lists. Исследовать различные варианты организации удаления записей и обработки повторных вставок.

4. **Реализовать поиск наиболее похожих чанков**
   
    Разработать алгоритм поиска наиболее похожих чанков. На первом этапе формировать множество кандидатов на основе общих признаков, после чего вычислять точную степень сходства только для отобранных кандидатов.

5. **Реализовать вычисление степени сходства между sketch**
   
    Реализовать вычисление коэффициента Жаккара для sketch и обеспечить поддержку sketch различного размера и различных типов признаков.

6. **Исследовать эвристики сокращения множества кандидатов**

   Исследовать методы уменьшения числа кандидатов, рассматриваемых при поиске: ограничение частоты встречаемости признаков, обработку редких признаков в первую очередь и предварительное отсечение кандидатов по порогу сходства.

7. **Исследовать и учитывать качество результатов поиска**

   Реализовать сбор статистики ложноположительных результатов и исследовать возможность использовать накопленную статистику для адаптации формирования и фильтрации кандидатов.

8. **Оценить эффективность обратного индекса**

   Измерить число рассматриваемых кандидатов, время работы и потребление памяти; исследовать влияние параметров поиска на скорость и качество результатов.

9. **Подготовить модульные тесты**

   Написать тесты, проверяющие соответствие индекса и операций с ним заданной спецификации.
