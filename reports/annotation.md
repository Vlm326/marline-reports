# Аннотация и название

## Название

## Краткая аннотация к теме






### Предметная область

Современные системы дедупликации данных используют не только поиск полностью совпадающих блоков, но и поиск похожих объектов. Для этой задачи применяются различные подходы, в том числе Content-Defined Chunking (CDC), основанный на алгоритмах скользящего хэша. Альтернативой CDC является Similarity-Based Chunking (SBC). В таких системах для каждого чанка строится компактное представление — sketch, содержащее набор признаков, по которому определяется степень сходства между чанками. 



### Проблема

Одной из основных проблем SBC является эффективный поиск похожих чанков среди уже сохранённых данных и выбор базового чанка. Прямой перебор всех имеющихся чанков требует сравнения запроса с каждым объектом, что становится неэффективным при больших объёмах данных. Для решения этой проблемы в работе рассматривается обратный индекс, сопоставляющий каждому признаку множество чанков, содержащих данный признак. При обработке запроса индекс позволяет предварительно ограничить множество потенциальных кандидатов чанками, имеющими общие признаки с запросом, а затем вычислять точную степень сходства только для отобранных кандидатов.

### Цель

Целью работы является разработка и исследование обратного индекса для базовых чанков, ориентированного на использование в алгоритмах SBC. В рамках работы планируется исследовать структуру хранения признаков и posting lists, алгоритмы вставки, удаления и обновления записей, поиск top-k наиболее похожих чанков, а также методы сокращения числа рассматриваемых кандидатов. Особое внимание будет уделено производительности индекса, потреблению памяти и влиянию параметров поиска на качество и скорость работы.

### Предполагаемые результаты

Результатом работы должен стать программный компонент обратного индекса на языке Rust, интегрируемый в общий pipeline дедупликации библиотеки MarLine.
